# 📚 Miniguia de Estudos com NotebookLM

## 📖 Contexto

Este projeto foi desenvolvido como parte do desafio da DIO com o objetivo de explorar o NotebookLM como ferramenta de aprendizagem ativa utilizando Inteligência Artificial.

O tema escolhido foi **Fundamentos de Inteligência Artificial Generativa e Engenharia de Prompts**, por ser uma das áreas mais relevantes da tecnologia atualmente e possuir grande aplicação no desenvolvimento de software e na automação de tarefas.

---

# 🎯 Objetivos

* Aprender os conceitos fundamentais de IA Generativa.
* Entender como o NotebookLM organiza conhecimento.
* Experimentar diferentes estratégias de Engenharia de Prompts.
* Criar um material de estudo reutilizável.
* Desenvolver habilidades de curadoria de conteúdo.

# ⚠️ Dificuldades Encontradas

Durante os testes foi observado que:

* prompts muito genéricos geram respostas superficiais;
* prompts específicos produzem respostas melhores;
* solicitar exemplos aumenta a qualidade das explicações;
* dividir perguntas grandes em partes facilita o aprendizado.

# 📘 Miniguia de Estudos

## O que é IA Generativa?

É um ramo da Inteligência Artificial capaz de criar novos conteúdos, como textos, imagens, códigos e áudios, a partir dos dados utilizados durante o treinamento.

---

## Principais aplicações

* Chatbots
* Assistentes virtuais
* Geração de código
* Criação de imagens
* Produção de documentos
* Tradução automática
* Resumos

---

## Boas práticas de Engenharia de Prompts

* Definir contexto.
* Informar o objetivo.
* Especificar o formato desejado.
* Informar o público-alvo.
* Solicitar exemplos.
* Refinar os prompts.

---

# 📖 Glossário

**IA Generativa**
Modelo capaz de gerar novos conteúdos.

**LLM**
Large Language Model, modelo de linguagem de grande porte.

**Prompt**
Instrução enviada para a IA.

**Contexto**
Informações fornecidas para orientar a resposta.

**Token**
Unidade de processamento utilizada pelos modelos de linguagem.

**NotebookLM**
Ferramenta do Google que utiliza documentos enviados pelo usuário para responder perguntas e organizar conhecimento.
